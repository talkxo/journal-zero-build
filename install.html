Install manually

iPhone & iPad

  1. Open Journal Zero in Safari (Chrome on iOS won’t install PWAs).
  2. Tap the Share button at the bottom of the screen.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top right.

Android

  1. Open Journal Zero in Chrome.
  2. Tap the menu (three dots) or look for an Install banner at the bottom.
  3. Choose Install app or Add to Home screen.
  4. Confirm when prompted.

Mac & Windows

  1. Open Journal Zero in Chrome, Edge, or Brave.
  2. Click the install icon in the address bar (monitor with a down arrow), or use the browser menu → Install Journal Zero.
  3. Confirm. The app opens in its own window.

Install needs a secure connection (HTTPS) when you host online. On your computer, localhost works for testing.
